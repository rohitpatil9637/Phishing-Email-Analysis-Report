# Phishing Email Analysis Lab
## Overview
Investigated 5 real-world phishing emails and documented findings, IOCs and responses.
## Method
8 steps: read, headers, sender/IP, links, attachments and images, verdict, report, respond.
## Tools
Kali Linux, VirusTotal, urlscan.io, AbuseIPDB, MXToolbox, Tesseract, zbar, ExifTool,
Python 3 (phish_triage.py)
